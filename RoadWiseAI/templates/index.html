About RoadWise AI

RoadWise AI is a Web GIS prototype for mapping road damage and supporting maintenance prioritisation in Thiruvananthapuram, Kerala.

Current development stages: interactive Leaflet mapping, manual map reporting, geotagged photo GPS extraction, integrated damage reporting workflow, and persistent PostgreSQL/PostGIS report storage.

Database Architecture & PostGIS Integration

Current status: Report details and locations are stored in PostgreSQL/PostGIS. Uploaded photographs are stored in the app's static/uploads folder.

PostGIS Schema: Each submitted report is stored as a spatial Point in SRID 4326. The app creates the report table and spatial index when it starts:

geom GEOMETRY(Point, 4326) NOT NULL · A GiST spatial index is created for location searches.

Demonstration incidents (A, B, C) are illustrative and not field-verified.
